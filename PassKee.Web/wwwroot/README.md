# PassKee Assets Bundle

## Directory Structure:
- `web/`:
  - `favicon.ico`: Multi-resolution icon (16x16, 32x32, 48x48)
  - `favicon-*.png`: Standard web favicons
  - `logo-cloud.svg`: Scalable high-res vector logo
  - `safari-pinned-tab.svg`: Monochrome vector for macOS Safari pinned tabs
- `pwa/`:
  - `icon-192x192.png`, `icon-512x512.png`: Standard PWA splash and launcher icons
  - `icon-maskable-*.png`: Adaptive maskable icons with safe zone margins
  - `site.webmanifest`: Ready-to-use PWA configuration
- `mobile/`:
  - `ios/`: Apple Touch icons (180x180, 167x167, 152x152)
  - `android/`: Android launcher mipmaps (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi)
- `extension/`:
  - `icon-16.png`, `icon-32.png`, `icon-48.png`, `icon-128.png` for Chrome / Firefox Extension Manifest V3
